# Portfólio — Samara Araújo

Site estático (HTML/CSS/JS) do portfólio pessoal.

## Como abrir

1. Abra o arquivo `index.html` no navegador (duplo clique ou arraste para o Chrome/Firefox/Edge).
2. Ou sirva localmente:

```bash
# Python
python3 -m http.server 8080 --directory .

# Node (se tiver npx)
npx serve .
```

Depois acesse `http://localhost:8080`.

## Estrutura

```
portfolio/
├── index.html
├── styles.css
├── script.js
├── assets/
│   └── cv.pdf

```

Não há build step — é HTML puro.
